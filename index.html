Verified Contributor Payroll

Pay ambassadors and contributors weekly, with each week released only when the work is checked. The money is locked in the contract, the rules are fixed when the plan is created, and paid weeks can never be taken back. Your own wallet signs everything here. Metis Andromeda, USDC.

Beta, unaudited contract. A plan holds at most 100 USDC. Use small amounts.

Start with an on-chain check: the agent verifies it from the chain and anyone can re-check it. Use admin sign-off only for work the chain cannot show.

The total (USDC per period x number of periods) is locked now. Each finished period is decided once by the agent or the admin, and that decision is final. Approved periods belong to the contributor. Rejected periods, and periods nobody decided in time (7 days for weekly plans, 1 day for shorter ones), return to you.

If you list yourself as the admin, you can reject any period, and the contributor will see that on-chain. Contributors should check who the checkers are before starting work.
